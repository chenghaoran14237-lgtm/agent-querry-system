## 接入阻塞需要的最小决策

要验收 External v1，需要平台负责人指定一个隔离测试部署及固定版本，并通过正常授权流程配置有效凭证和 API origin。不要恢复旧客户端、扩大公共访问范围或为测试开放任意 SQL。

本次重新连接（2026-09-08 13:17 UTC）直接请求 `GET /api/external/v1/conversations`，服务返回 HTTP 401 `invalid_credentials`。这证明公共路由仍然存在，但没有凭证时不能证明部署、会话或 Agent 运行可用；本次没有继续尝试创建会话。

预期用途需由负责人确认：仅运行页面生成 Agent，还是也允许受控元数据/查询工具。如果要开放医院数据，需明确数据源、表、列、动作和用户范围。业务写回单独授权，不由这次接入审计推定。

获得合法测试接入后，先执行一条不含患者信息的最小探针，验证 ID、状态、事件、最终消息和同访客恢复；再按获准的能力逐层验收。当前没有新建/修改草稿作为绕行测试。

python3 scripts/audit_platform.py --username demo_admin --allow-http
